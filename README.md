# Perfil personal — Landing

Este repositorio contiene una landing sencilla y personalizable para presentar tu perfil, progreso y proyectos.

Cómo usar:
1. Reemplaza los datos en js/script.js (PROFILE, PROJECTS, SKILLS, TIMELINE).
2. Añade tu avatar en assets/avatar-placeholder.svg.
3. Sube a GitHub Pages o cualquier hosting estático.

Si quieres, yo puedo:
- Subir estos archivos al repo si me confirmas el owner/repo.
- Añadir integración con GitHub Actions para desplegar en Pages automáticamente.
- Convertirlo a Next.js o plantilla React.
