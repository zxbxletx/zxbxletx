# Portafolio profesional — Juan José Zabaleta (zxbxletx)

Esta versión del repositorio ha sido personalizada con los datos profesionales de Juan José Zabaleta para que sirva como landing page al visitar el repositorio.

Qué incluye:
- Página estática (index.html) con secciones: Sobre mí, Proyectos, Habilidades, Experiencia y Contacto.
- js/script.js pre-llenado con datos del CV (nombre, contacto, experiencia, proyectos, skills).
- Estilos responsivos en css/styles.css.
- Workflow de GitHub Actions para desplegar en GitHub Pages (rama main).

Instrucciones rápidas:
1. Si quieres que el enlace "Descargar (PDF)" funcione, sube tu CV en PDF a la raíz del repo con el nombre `CV.pdf`.
2. Revisa y personaliza `js/script.js` si quieres ajustar descripciones, niveles de habilidad o añadir enlaces directos a proyectos.
3. Para cambiar la foto de avatar, reemplaza `assets/avatar-placeholder.svg` por tu imagen (puedes usar `assets/avatar.png`).
